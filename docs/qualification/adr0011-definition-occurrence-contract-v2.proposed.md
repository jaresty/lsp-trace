## Evidence and unresolved authority

The existing contract §§1–4 proposes source-bound queries, strict shapes, all-or-none target admission and leases; `adr0011-definition-contract-review-decision.md` says REVISE. `schemas/adr0011-definition-result.proposed.schema.json` validates decoded complete result shapes only; `policies/adr0011-definition-exact.proposed.json` sets `framedWireCapBytes:null`. Neither registers a receipt. `schemas/adr0011-production-admission-v1.proposed.schema.json` constrains `COMPLETE_EMPTY` to E=P=0, while the definition draft proposes E=P=2, A=0, EXCLUDED with `COMPLETE_EMPTY`. The maintainer's **proposed definition-only resolution** is a separate `EXCLUDED_VERIFIED` terminal for a verified nonempty exclusion, not `COMPLETE_EMPTY`; this decision is no longer undecided. Its exact-byte terminal schema and policy remain unwritten/unreviewed, so this proposal does not authorize issuance or borrow references production-admission authority or `returned_range` as a definition target and selection pair.

## Normative byte and state grammar proposed for review

A strict parser consumes one bounded UTF-8 JSON value followed by only permitted whitespace. Reject invalid UTF-8/escapes/surrogate pairs, duplicate **decoded** member names (e.g. `"uri"` and `"\u0075ri"`) *before* decoded-schema validation, extra/missing/case-aliased fields at any nesting level, invalid coordinate number tokens and trailing values. Preserve exact original bytes, length and SHA-256: reserialization is not the original. JSON Schema alone cannot prove byte uniqueness, source bounds or event history.

Complete result grammar: `null | Location | Location[] | LocationLink[]`. Arrays are homogeneous; `[]` is EMPTY_ARRAY with no inferred element type. Location has exactly `{uri,range}`; LocationLink exactly `{targetUri,targetRange,targetSelectionRange,originSelectionRange?}`; Range exactly `{start,end}`; Position exactly `{line,character}` with nonnegative integral coordinates. Scalar Location is valid, E=1, ordinal 0; scalar LocationLink is MALFORMED. Mixed arrays, null/nested members or **any** malformed member make the whole result MALFORMED, P=A=0: a valid prefix is diagnostic only. E is a bounded complete top-level count or UNKNOWN, never invented zero; truncation never becomes `[]`.

Location has only its own `range`. Each link retains distinct `targetRange` and contained `targetSelectionRange` originals even if equal. Require start<=end and exact supplied-source UTF-16 boundaries. Optional `originSelectionRange` retains present/absent distinction; when present its endpoints, encoding and source version MUST exactly equal the independently prederived query occurrence range. Mismatch makes whole result MALFORMED, P=A=0. URI canonicality and initial Go profile's absolute local `file:`/registered-root custody require semantic checks. No references `returned_range` alias or inferred selection range.

Raw `null` and `[]` each have E=P=A=0, but distinct original bytes, shape, digest and receipt identity. Equal targets at ordinals 0 and 1 retain distinct occurrence IDs bound to transaction/query, target originals and ordinal. A transaction-scoped candidate ID may coincide; it cannot collapse occurrences or grant cross-query identity. Freeze candidate/occurrence encoding and collision domain independently.

## Independent original-byte admission

Before invocation the host independently selects immutable source URI/version/encoding/bytes/digest, registered root and clean Git/HEAD before/after, caller-asserted revision (not HOST_OBSERVED_GIT), READY session/generation, provider executable/version/profile and initialization capability, range adapter, method/admission/privacy/retention policy, bounds and query declaration. A versioned language adapter must derive one source identifier and half-open UTF-16 range (first Go profile: cursor at start/interior, not end or surrogate interior). Zero, ambiguous, over-bound or stale derivation means zero invocation. CUE/other languages require separate qualified adapters and provider profiles.

The source-bound query occurrence MUST be independently derived, no-replace published and replay-verified against exact source URI/version/digest/range and identity **before** `textDocument/definition`; no response or test-only references declaration creates it. Freeze exact raw params (`textDocument:{uri}`, `position:{line,character}`), digest, collision-safe invocation, session/generation and separately observed definition capability. Byte-different semantically equal params identify different transactions. Missing capability/query receipt gives zero invocation, B=T=A=0. The manager's **actual key** is selected only after owner-observed completed framed WRITE, bound to WRITE selector/digest/length and invocation/generation in a separate key-observation original; pre-WRITE declarations cannot assert it. Independently match response ID and completed read; WRITE does not prove provider receipt. Every target source requires independent exact URI/version/digest/bytes; never ambient checkout fallback, substituted generation or silent retry.

Closed exact-byte roles: capability; pre-invocation query; method/WRITE-key/read/raw result presence; evaluator and top-level count; partial-wire observation; each target source; terminal/accounting; occurrence ledger; dependencies/active manifest; redacted failure diagnostic; and **external** publication verification. For each, freeze registered schema URI/version/exact bytes/hash, canonical encoder/fixture and strict nested replay, selected policy exact bytes/hash, executable implementation digest, independently selected predecessor selectors/lengths/digests and exact readback. A role string, claimant self-hash or embedded `verified:true` does not establish an original.

Freeze initial proposed Go/gopls limits **per affected role**: N<=16/acquisition; one query/request; targets<=1000; params<=65,536 bytes; result<=524,288 bytes; canonical record<=1,500,000 bytes; messages<=4; Manager-counted decoded JSON-RPC bodies<=1,048,576 bytes; **separate positive framed-wire cap still unselected/unobservable**; deadline 15,000 ms; document<=262,144 bytes; requests/query<=21; total documents/query<=4,194,304 bytes; evaluation work<=100,000; retained canonical bytes/acquisition<=134,217,728. Freeze units/precedence and independent at/over-limit fixtures. Host-only private 0700 root, no-replace 0600 receipts, default-off issuance, private raw params/result and redacted diagnostics need pinned privacy/retention originals. Withheld mandatory bytes prohibit issuance. Proposed no-auto-expiry grants no retention authority.

## Evaluator, exclusion and publication

Record `QUERY_BEGIN` only on actual evaluation start; bounded complete top-level count yields E (including 1001) or UNKNOWN. Each inspected ordinal has observed `ELEMENT_BEGIN` (half-open offsets/digest into exact **result payload**) then one evaluated terminal event; no inferred events from parsed slices. `WHOLE_PARSE_SUCCESS` establishes P only after all members pass. Require 0<=T<=B<=N; if E known, 0<=E_T<=E_B<=E, 0<=P<=E, 0<=A<=P. Internal E_T may be provisional; T needs verified terminal readback. Counting over work/byte bounds yields E=UNKNOWN. Failure precedence: transport/revision/policy/capability, presence/byte/wire/work limits, count, strict parse, source eligibility, publication; no later stage erases an earlier failure.

Partial frames require Manager-owned bounded **JSON-RPC body-prefix** original, observed Content-Length/framed-wire bytes, completed WRITE/pending actual key, read phase, exact prefix bytes/digest and cause. A bounded strict scan must find exactly one matching response ID before result prefix and complete member spans before recording prefix events. Body-prefix offsets are not result-payload offsets. Missing/ambiguous ID, incomplete member, withheld prefix, uncheckable duplicate or unavailable seam leaves E=UNKNOWN and prefix counters unproven: fixture INCOMPLETE. Neither completed RoundTripResult nor reconstructed prefix establishes observed partial wire.

Keep observed method shape, internally evaluated E/P, aggregate request outcome/query disposition, committed publication and independently verified **issuable terminal** distinct. Precommit failure has no verified receipt; committed-unverified bytes are quarantined `PUBLICATION_UNVERIFIED`, outcome null, T=0, newly issued A=0, while internal observations stay provisional. Independent no-replace readback of selected originals and separate fresh final readback gate issuance. Pre-invocation failure is not an empty result; MALFORMED/PARTIAL/RESOURCE_LIMIT/CANCELLED/TIMEOUT/UNSUPPORTED/PROVIDER_FAILURE retain distinct causes.

For a fully parsed two-target definition result with exactly one unavailable exact target source, the proposed outcome is definition-only `EXCLUDED_VERIFIED`: E=P=2, A=0, query disposition `EXCLUDED`, no admitted occurrences, never EMPTY or invented raw `[]`. Evaluator observations alone are not a verified terminal: observed E_B=E_T=2 and target events can establish a complete evaluation record but do not themselves establish T=1. `EXCLUDED_VERIFIED` is issuable only after independent verification of the complete two-member denominator and every required evaluator event (including both per-ordinal terminal events and `WHOLE_PARSE_SUCCESS`), exact target-source evidence establishing the one unavailable source, all-or-none exclusion, committed no-replace publication and independent verification of its selected originals plus separate fresh final readback under a reviewed definition-only terminal schema/policy; only then is definition-specific T=1. If E is UNKNOWN, any event is partial/missing, or the denominator is not independently verified complete, no verified terminal is issuable. Precommit failures yield no verified receipt; committed but unverified publication remains quarantined `PUBLICATION_UNVERIFIED`, outcome null, T=0 and newly issued A=0 even if evaluator events were observed. `EXCLUDED_VERIFIED` is distinct from `COMPLETE_EMPTY`, which the proposed production-admission schema restricts to E=P=0; that references schema conveys no definition authority. True `null`/`[]` may receive empty disposition only under separately accepted schema and verified denominator.

## Lifecycle, falsification and stop

Active ledger pins query/method/target-source/terminal/payload dependencies. A reader holds root shared lease throughout eligibility-dependent use, verifies latest manifest generation and each dependency, rechecks before return; released lease invalidates cached eligibility. Exclusive retire/revoke checks predecessor generation/digest, boundedly waits, publishes complete-set tombstone **before** deletion; stale predecessor/timeout aborts without deletion or claimed revoke. Active dependents block ordinary removal; failed deletion quarantines, unexplained absence is integrity failure. Cross-process behavior is proposed, not implemented.

Independent synthetic controls must vary scalar Location/link; homogeneous/mixed/malformed-member arrays and escaped duplicate; raw null/[]; each link range/containment/origin; query source/range/receipt, params byte, generation, capability, post-WRITE key; equal ordinals; unavailable source of two; partial matched/missing ID, E UNKNOWN/zero and event omission; precommit/committed-unverified, withheld privacy; each numeric cap in isolation; and lease/revoke interleavings. Each row needs exact originals, independent expectations, N/B/T/E/E_B/E_T/P/A, precedence/readback and nonissuance verdict. Synthetic passes cannot qualify real clean registered Go/gopls evidence. Keep references/CALLS non-regression distinct; no implementation or qualification occurs in this step.

The result `$id` `https://jaresty.github.io/lsp-trace/qualification/proposed/adr0011-definition-result.v1.schema.json` is proposed, **not a registered receipt schema**. `docs/qualification/policies/adr0011-definition-exact.proposed.json` is unaccepted/unpinned for issuance. Seven role outlines in `adr0011-definition-schema-boundaries.proposed.md`, plus partial-wire/source/diagnostic/publication roles, lack accepted registered URI, exact schema/policy bytes and digests, canonical fixtures and implementation pins; inventory file hashes do not close this. A new definition-only exact-byte registered terminal schema URI/version with explicit `EXCLUDED_VERIFIED` enum/role and selected policy is **REQUIRED but UNWRITTEN/UNREVIEWED**; its contract must bind the issuance predicates above and keep observed evaluation separate from verified terminal status. Freeze those originals and source/revision/capability/profile/limits per role; choose observable framed cap and decide candidate identity authority. The nonempty EXCLUDED outcome choice is resolved for this proposal, but schema registration/review, policy and remaining independent authority/qualification blockers keep it **REVISE** until accepted.
