# ADR0011 generic LSP exact admission — correction decision packet

**Status: PROPOSED / independent maintainer review required. Authority: 0.** This records the requester's revised direction, **not** an accepted policy, schema, provider profile, occurrence qualification, or implementation authorization. No acquisition, qualified row, public/production enablement, grouping run, or semantic feature acceptance follows. Do not modify the accepted references V1 contract or its 21 final-reference dependencies by reading this packet as an amendment.

## Decision requested and existing boundary

The requested successor direction is `GENERIC_LSP_DEFINITION_EXACT_V1` and `GENERIC_LSP_REFERENCES_EXACT_V1`: any standards-compatible LSP may be *eligible to attempt* full generic ADR0011 admission without a maintainer-created per-provider profile or allowlist. Generic means common method/shape/custody/replay gates, **not** trusting an unknown provider, treating an advertised capability as semantic correctness, or waiving original bytes. Optional provider-specific refinements may narrow or annotate a separately selected use; their absence must not itself disqualify a standards-compatible server under the proposed generic path.

This is a **change request**, not the current accepted rule. `adr0011-production-admission-gate.review.md` §2 selects only `GO_GOPLS_EXACT_V1`, an exact READY Go/gopls session and clean registered Git worktree, and bars arbitrary providers; its 162-row normative occurrence matrix (`adr0011-occurrence-falsification-matrix.review.md`) names real Go/gopls qualification. `adr0011-references-contract-implementation-acceptance.md` accepts that references contract *for implementation only*, not occurrence-specific `QUALIFIED`. The built-in `BUILTIN_LOCAL_REFERENCES_V1` profile (`profiles/adr0011-builtin-local-references-v1.proposed.json`) binds fixed policy/schema digests, plan/selection identity, subordinate document-symbol target and immutable local executable measurement; it is not a provider-independent admission license. The subsequent references issuance addendum is proposed, not a silent override of the accepted gate. **Generic references conflicts the accepted existing product/implementation direction and requires a separate explicit maintainer decision and additive versioned successor contract, matrix and qualification.** Historical V1 receipts, profile identity, 21 final refs, ordinals, replay and omitted-selector `CALLS_ONLY` remain intact; no retroactive reinterpretation.

Definition is a different status: `policies/adr0011-definition-exact.proposed.json` still names `GO_GOPLS_DEFINITION_EXACT_V1_PROPOSED`, has a null framed cap and is unaccepted. `adr0011-definition-occurrence-contract-v2.proposed.md` and definition terminal V2 propose additional exact-byte/`EXCLUDED_VERIFIED` semantics, not an accepted generic profile. The earlier `adr0011-definition-wire-profile-decision.packet.proposed.md` recommends an every-complete-frame ceiling but asks for a gopls/provider pin. **Supersede that packet's pin recommendation for this proposed decision only**; retain its wire observation/precedence distinctions. Do not freeze its identity option B as a gopls allowlist. ADR0011 (`docs/adr/0011-versioned-definition-reference-grouping-evidence.md`) allows staged additive typed evidence under authority zero but currently names the first Go/gopls references profile and a separately pinned CUE held-out profile; generic admission does not itself repeal those downstream held-out/provider-specific qualification requirements. ADR0007 (`docs/adr/0007-optional-local-semantic-feature-index.md`) keeps generated index/group outputs provisional and independently adjudicated.

## Proposed generic admission invariant (not yet frozen)

For each transaction, owner-select and retain the **configured executable path/URI, launch argv and relevant configuration, measured complete executable bytes with length and SHA-256, measurement phase/status and same-generation correspondence**, plus reported `serverInfo.name` and `serverInfo.version` **when present** (including explicit absence), negotiated position encoding, required advertised method capability, adapter identity/version, exact READY session ID/generation, workspace/revision custody and exact source supply. These fields are dynamic transaction identities, not comparison to an allowlisted build/name/version. A changed executable, arguments, reported version, encoding, capability, adapter or generation creates **distinct evidence** requiring new independent binding/replay; it is not automatically rejected solely because the provider is new. A raced/unavailable required executable-byte measurement, inconsistent transaction identity or changed bytes *within the same claimed transaction* fails closed. A measured local executable is not a cryptographic attestation of the responding process or server's semantic honesty; reported metadata is a server assertion. Do not claim provider authentication or build provenance. Whether the managed owner can actually establish full original executable bytes and process correspondence is a pre-freeze implementation/custody question, not an excuse to substitute a digest supplied by the provider.

A generic adapter parses the standard `textDocument/definition` (`null`, `Location`, `Location[]`, `LocationLink[]` per selected strict contract) or `textDocument/references` (`null`/location array per selected strict contract), retaining exact raw request parameters, completed keyed write/read and exact original result token bytes, strict duplicate-key/trailing-field checks, original ordinals and equal-return multiplicity. Mixed Location/LocationLink arrays, scalar LocationLink if not selected, malformed members and incomplete denominators never become complete successful occurrences by normalization. The existing references V1 subordinate uniquely selected document-symbol query-target cannot be silently dropped: generic references needs a pre-existing independently admitted target identity or an explicitly reviewed alternative derivation, before invocation, with exact query and source binding. Definition result targets and reference target identity must remain separate typed semantics, never `CALLS`.

**Pre-invocation query source is language-dependent, not an eligibility profile.** If a caller supplies exact URI plus position, no language parser is needed merely to derive a query coordinate; still verify a replayable, independently owner-bound exact source URI/version/digest/**bytes**, encoding and position boundary, managed generation, workspace/revision custody, query declaration/params and method capability before invoking. If a query begins from a symbol, identifier, range or language syntax, the selected derivation must establish the exact source point and unambiguous relation to that symbol by an independently replayable language-aware or server-reported receipt. No generic LSP rule may infer a Go identifier range for every language, assume UTF-16 regardless of negotiation, or manufacture source from a checkout. Cross-document target source requires independently admitted exact URI/version/digest/bytes for each target; unavailable or privacy-withheld mandatory source fails the selected occurrence admission (while an independently supported definition-only excluded terminal may record a complete evaluation without occurrences). Never equate source-context projection completeness with occurrence admission without a separately selected contract.

**Selected wire scope:** `EVERY_COMPLETE_INBOUND_FRAME`, inclusive **2,097,152 actual consumed bytes per complete valid LSP frame**, header plus body, including matched result, error, notifications and unrelated responses observed during the transaction. Exactly 2,097,152 is within this wire bound; 2,097,153 is over. `Content-Length`, body-only size, buffer prefetch and re-marshaled decoded size are not substitutes. Compare every observed complete frame first; then independently apply the selected decoded-message/body ceiling (definition proposal: 1,048,576), raw result ceiling (definition proposal: 524,288; references V1 has its own 1,048,576 exact-result limit), and positive transaction message/cumulative bytes/deadline/work/allocation limits. Preserve earliest causally observed terminal reason; an earlier unrelated over-limit frame cannot be forgiven by a small matched result. Partial frame/EOF has no asserted complete-frame length and needs its own bounded partial-read/work disposition. Current `FrameBytes` observation and private 2 MiB correspondence limit are not proof that runtime enforces this admission ceiling. Whether one shared generic wire policy can select those other method-specific limits and precedence needs explicit review.

Mandatory original bytes are non-substitutable: missing/withheld exact executable measurement (if selected mandatory), pre-invocation source, request params, owner-observed keyed write/read, result slice, terminal events, selected schema/policy and dependent receipts, or fresh final readback means no **new** admitted occurrence or successful verified terminal. Re-serialization, self-consistent hashes without originals, an ambient read, a provider label, or replay against latest generation cannot heal absence. Provisional evaluation counters and independently verified final issuance remain distinct; committed-unverified publication is quarantined rather than promoted or rewritten. Historical immutable issuance is not retroactively erased by later replay loss.

## Authority-zero ceiling and downstream separation

A successful generic admission would attest only to a bounded, exact, typed server-reported transaction and replayable occurrence identity under declared custody/limits: `authority=0`, `accepted=false`, `completeness=UNKNOWN`, with no producer authentication. It does **not** prove semantic correctness, accepted symbol identity, source/repository completeness, runtime dispatch/`CALLS`, feature identity, ownership or production use. Admission makes an occurrence eligible for a separately versioned typed indexing/grouping input only after that input's own admission and qualified composition policy. It does not itself run Leiden, qualify a grouping policy, supply CALLS-only representative/outward-consumer semantics, authorize CLI/MCP exposure, or accept a feature. ADR0007 feature inventory and semantic feature identity still require independent human/stakeholder adjudication and correction; indexability and grouping eligibility are not acceptance.

## Falsification matrix for the proposed successor

Each scenario needs frozen originals, independently selected expectations, observed `N/B/T/E/E_B/E_T/P/A` (unknown is not zero), publication/readback status and a nonissuance or distinct-identity verdict. These are proposed controls, **not executed qualification rows**; references V1's accepted 162 rows are not replaced.

| Independent witness | Required generic verdict |
| --- | --- |
| Unknown but standards-compatible provider with verified dynamic identity, capability and originals | Eligible to attempt generic admission without a new maintainer profile; success only after all method/custody/replay gates, never authentication. |
| `serverInfo` absent, or name present/version absent | Represent exact absence; do not reject solely for absent optional metadata; fail if any asserted value disagrees with retained same-transaction observation. |
| Executable bytes/path or argv/config changes between transactions; reported version changes | Different transaction evidence/identity; no provider allowlist rejection. Change within one claimed transaction or mismatched replay rejects that transaction. |
| Method capability false/absent or nonstandard shape despite claimed capability | No invocation when unsupported; nonstandard result fails strict selected method grammar, not coerced into a complete empty/valid occurrence. |
| UTF-8/UTF-16/UTF-32 negotiation or changed encoding, invalid point/surrogate boundary | Bind negotiated encoding to exact source and params; changed identity is distinct; invalid or mismatched point rejects before invocation. |
| Session generation or workspace revision stale, dirty, unavailable, or before/after custody disagrees | Reject new admission under selected custody; no reuse of prior generation/source or inferred provider-verified Git. |
| `null` versus `[]`, two equal locations, mixed Location/LocationLink or malformed later member | Distinct exact bytes/empty identities, preserve equal ordinal multiplicity; mixed/malformed cannot silently produce success or prefix A. |
| Query or one target source bytes unavailable/withheld, or references target identity missing/tied | No newly admitted occurrence; do not relabel nonempty as empty. A definition excluded terminal requires its own reviewed complete-denominator policy. |
| Complete unrelated/notification/error frame at 2,097,152 then small matched success; at 2,097,153 then small matched success | First passes wire comparison (other limits still apply); second fails wire even though matched result is small. Isolate decoded/result/message limits. |
| Replay with missing original, altered params/result/ordinal/capability/provider identity/policy or latest-generation substitution | Reject new replay/issuance despite self-consistent replacement hashes; retain original historical record without rewriting. |
