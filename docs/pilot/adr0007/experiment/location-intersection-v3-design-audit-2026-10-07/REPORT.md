# ADR 0007 Location v3 design audit

Verdict: **LOCATION_DESIGN_BLOCKED**

Freeze: `sha256:2a47c53e61be31711f3e2486b1e000c325cd1d6c0f569cf8c2352297363ed081` (`47,769` bytes; 319 entries)

V3 added an exact sorted census and rejected ordinary omissions, unlisted files, duplicate/reordered entries, substitutions, traversal, malformed digests, symlinks, and special files. It remains blocked for three independently demonstrated defects:

1. the verifier treated a missing root `FREEZE.json` as success;
2. census excluded every nested file named `FREEZE.json`, not only the root manifest;
3. expected case outputs were generated by the same evaluator later used to verify them, so the corpus lacked an independent semantic oracle.

V3 is immutable. A successor must require the root manifest, exclude only that exact manifest from census, retain nested same-name files, and compare runtime results against independently authored literal expectations or a genuinely separate reference oracle covering all 24 cases.

No `LOCATION_DESIGN_GO`, qualification execution, semantic acceptance, feature identity, completeness, production authority, public surface, release, or push is established. Ceilings remain `authority=0`, `accepted=false`, `completeness=UNKNOWN`, and `featureIdentity=UNRESOLVED`.
