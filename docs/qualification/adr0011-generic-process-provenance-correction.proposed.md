# ADR0011 generic PROCESS provenance correction — proposed

**Status:** proposed contract correction; authority 0. This packet supersedes `adr0011-generic-launch-retention-expiry.packet.proposed.md` only where it requires complete executable-chain measurement, retained executable bytes, process correspondence, or fail-closed issuance on missing launch evidence. It does not supersede the accepted references V1 contract, its Go/gopls gate or original IDs, nor silently select any pending generic schema, policy, selector or publication role. The companion `adr0011-generic-lsp-admission-successor-v1.proposed.md` remains an implementation-only proposal. Neither document qualifies a provider, authenticates a producer, activates a lifecycle, or authorizes public issuance.

## Admission boundary

A generic admitted occurrence requires independently held exact query source URI, version, bytes and digest, exact point under the negotiated encoding and original request params; owner-observed initialize and ordered registration/unregistration capability events effective at the pre-WRITE snapshot; completed framed WRITE and actual request key; consumed original inbound frames and matched result; exact returned target source; verified terminal and denominator accounting; no-replace private publication, independent readback and fresh replay against selected originals. Missing mandatory transaction evidence prevents exact admission under the companion proposal's typed dispositions. Process launch, executable provenance, and a complete dependency chain are **not** gates on attempting or admitting an otherwise eligible generic occurrence. This separates transaction evidence from contextual PROCESS observation; it does not assert receipt of a WRITE by a server, response authorship, producer authentication, runtime dispatch, source completeness, semantic feature identity or production authority.

## PROCESS observation, not response attribution

Record only the observation justified by the owner's custody: `LOCAL_EXECUTABLE_MEASURED` when the selected local executable file was measured; `LOCAL_CONFIGURATION_ONLY` when local launch configuration is observed but executable measurement or dependency closure is unavailable; `EXTERNAL_PROCESS_UNMEASURED` when the process is externally managed and no local executable measurement is owned. These states describe PROCESS provenance, not an admission tier or a verified executable chain. A local measured path, file length and digest say what file was observed at measurement time, not which executable produced the inbound response. A wrapper, Java launcher, interpreter, symlink or unknown transitive dependency does not turn a measured file into complete process correspondence. Server-reported name/version remain optional assertions. Never infer the response-producing executable or response authorship from any of these states.

## Selected bounds and time semantics

Select a mandatory **67,108,864-byte** cap on retained transaction originals, measured against the cumulative retained original bytes of the exact transaction (including query/params, capability events, WRITE, inbound frames/result, source and target, terminal/accounting and publication/replay evidence). Launch binaries are excluded from this mandatory transaction cap and are not mandatory originals. Content-addressed metadata referring to a retained original counts its own retained bytes once; repeated references to the same content-addressed original do not count that original repeatedly, and distinct stored originals cannot be hidden by aliasing. Optional executable snapshots, if separately selected, remain private, use a separate explicit budget and retention policy, and cannot repair missing transaction originals or become an implicit admission prerequisite. This selected cap is an independent aggregate admission ceiling, **not** a promise that all independently category-valid maxima fit simultaneously. Before each no-replace publication, the owner reserves the worst-case additional mandatory originals and metadata with checked arithmetic against 67,108,864 B; unknown-length inputs use an independently bounded maximum reservation, then reconcile to exact measured charges. Each distinct content-addressed blob is charged once only after exact-byte verification, while every role/ref and manifest is charged as metadata even when sharing a blob. If the complete mandatory set cannot fit, return typed `RETENTION_QUOTA_EXCEEDED` before an issuable terminal, with no partial selector; committed-but-unverified bytes remain quarantined. A failed reservation cannot be healed by omitting required source, event or publication originals. At-cap/+1 aggregate fixtures must keep every category individually within its bound and measure all metadata charges; when that is impossible at the fixed cap, an isolated test-only aggregate quota seam may test Q/Q−1 without claiming the exact 67,108,864 B boundary was exercised. This selected cap is a proposed successor requirement, not a retroactive reinterpretation of references V1 or an implementation claim.

An eligible same-process access is unexpired only for monotonic elapsed time **strictly less than 86,400,000 ms** from its recorded start; equality is expired. Initially disable cross-process access or replay until a separately accepted durable epoch/time mechanism defines trustworthy elapsed-time reconstruction. An expired access is denied; expiry alone does **not** delete, revoke, or prove removal of retained private bytes. A later retention/deletion policy requires separate selection. A clock reset or missing same-process start cannot be treated as unexpired by default.

## Proposed negative falsification controls (not executed)

| Contrast | Required distinction |
| --- | --- |
| Local measured binary changes while all transaction originals remain unchanged, versus unchanged binary and unchanged transaction originals | The PROCESS observation changes, but identical transaction evidence is not invalidated or reattributed by the binary observation alone. Neither case proves the responding executable. |
| Externally managed, unmeasured process with complete transaction evidence | `EXTERNAL_PROCESS_UNMEASURED` remains eligible to attempt generic admission; no local binary is invented or required. |
| Wrapper or Java launcher measured locally with unknown dependencies, with complete transaction evidence | `LOCAL_EXECUTABLE_MEASURED` describes only the measured file; unknown dependencies do not block the attempt or become a complete executable-chain assertion. If only launch configuration is known, use `LOCAL_CONFIGURATION_ONLY`. |
| Process measurement present but WRITE, inbound original, exact target source, terminal or publication/replay original missing | PROCESS evidence cannot cure the missing mandatory transaction original. No exact admitted occurrence follows. |
| Locally measured executable and matched inbound result | Neither the measurement nor request-key match authenticates the producer, establishes which executable produced the response, or proves response authorship. |
| Mandatory originals separately satisfy wire/source/event caps but their checked aggregate plus metadata exceeds 67,108,864 B by one | Reject before an issuable terminal with `RETENTION_QUOTA_EXCEEDED`; no category maximum grants an over-quota exemption or permits omission of required originals. |
| Same-process elapsed time 86,399,999 ms versus 86,400,000 ms; cross-process access without accepted durable epoch | Only the first is within the strict expiry bound; equality expires, and cross-process access stays disabled. Expiry itself is not deletion. |

**Review boundary:** This correction narrows the superseded launch-chain claims and adds proposed cap and expiry semantics; it makes no schema, policy, code, qualification, live-provider, public-interface or lifecycle change. Independent review must select any unresolved role originals and optional snapshot policy before implementation can claim closed exact issuance. Preserve immutable original IDs and V1 references unchanged.
