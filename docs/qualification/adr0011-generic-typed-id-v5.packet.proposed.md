Schema only constrains parsed request/response ID **kind** to JSON string or number. It cannot prove matching request/response originals, raw token custody, duplicate-free raw frames, exact decimal equality, or host-held completeness. The exact ID token is retained **inside each complete original framed request and response**. No normalized ID replaces or overwrites that evidence. If a pending response has no frame, it has no response ID and cannot establish correspondence. A response with `error` and `id:null` cannot match a retained request.

## Transport correspondence and proposed finite bounds

Before capability-state evaluation, parse complete framed JSON-RPC 2.0 request and response, reject duplicate decoded keys and malformed or non-JSON constants, and require both IDs to be strings or numbers of the same kind. Strings compare by exact decoded UTF-8 value (escaped/literal equality); numeric values compare by exact decimal coefficient/power, without binary floating-point conversion or zero-string expansion. Thus `1`, `1.0`, and `1e0` match; `"1"` and `1` do not; distinct integers above 2^53 do not collide. The offline candidate bounds each raw ID token to 4,096 bytes, a decoded string to 1,024 UTF-8 bytes, an explicit exponent magnitude to 100,000, and each complete frame to 2,097,152 bytes. Exponents are parsed in bounded work and compared as coefficient/power; no exponent-sized allocation is allowed. These numbers are proposed V5 bounds, not V4 policy retrofits or production admission.

`internal/adr0011genericv5proposal/id.go` is a testable offline guard, not B4 replay. `CandidateState` calls its supplied state callback only after `ValidateFramedPair` succeeds. Go and Python fixtures execute original escaped raw-token boundaries at 4,096/4,097/4,202 bytes, a small decoded value with oversized escaped raw bytes, decoded UTF-8 string boundaries at 1,024/1,025 bytes, number raw cap/cap+1, and equivalent numeric spellings. The Python validator locates the top-level decoded `id` key and measures its value's exact UTF-8 lexical span in the original framed body, including quotes and escapes; it never substitutes `json.dumps` or decoded length for that span. Other Go fixtures execute boolean/null/container rejection, string/number mismatch, exact decimal and escaped-string equivalence, non-equal and >2^53 decimals, extreme exponents, duplicate decoded `id`, malformed numbers, NaN/Infinity, valid matching-ID error responses, and null-ID error rejection. The boolean guard was perturbed to accept a boolean, observed the named `SUPPORTED`/`state_evaluated=true` RED, restored, and passed the named GREEN.
