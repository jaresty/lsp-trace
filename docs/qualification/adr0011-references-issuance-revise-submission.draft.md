The profile remains proposed. Hosted/shared/remote/centralized/automatically CI-retained operation is unsupported, not a later acceptance gate; adding it would require a new ADR. ## Predeclared falsification before seeking ACCEPT

1. Omit, duplicate, reorder, forge after parsing, or cross an invocation boundary with an evaluator event while preserving a plausible item array: no proposal or issued `T/A`. Change scanner count while events/items remain plausible: replay fails.
2. Fail precommit and committed readback at method, raw, scanner, events, proposal, candidate and final. Retain exact potentially committed ref in bounded private redacted **transaction uncertainty metadata** on committed uncertainty; issue `T=A=0`, no retry/retro-upgrade.
3. Substitute each source/revision/policy/schema/implementation/ref/digest and each ordinal or range one at a time; a self-consistent candidate without final cannot admit. Preserve duplicate equal locations as distinct original ordinals.
4. Exact 1 MiB and 1 MiB+1 under an owner-eligible Manager; independent wire/staging/Manager/message/work/allocation/deadline edge/+1 controls. Mark any shadowed boundary `INCOMPLETE`.
5. Synthetic secret canaries in valid and malformed bytes, server error message/data/code, URI, source, provider error, logs and uncertain-publication metadata: absent from D/ordinary CLI/MCP/error/log/metadata; raw only in explicitly opted-in local capture. Code zero included in both explicitly authorized and default-withheld controls. Verify fixtures contain no copied real secrets and that the tool does not intentionally upload, commit or copy live raw to known synchronized/CI-managed locations; do not demand proof of host-level backup settings.
6. Exhaust issuance transaction and local raw caps separately; simulate uncertain committed final readback, local raw manual deletion, active final dependency and missing replay. Block new issuance on uncertainty; deleted debug bytes return the affected row to `INCOMPLETE` unless a sanitized synthetic fixture independently replays the claim. Do not silently evict or promote.
7. Omitted-selector historical `CALLS_ONLY` schema/output byte controls, separately from references behavior. Execute the full 162-row matrix later against pinned implementation and clean managed Go/gopls evidence; shape tests are not this evidence.
