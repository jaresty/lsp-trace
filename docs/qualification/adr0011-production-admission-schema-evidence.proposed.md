# ADR0011 production admission schema evidence — unaccepted

Implementation-only proposal. No live capture, matrix row, public PublishReferences, CLI/MCP enablement, index or definitions. The accepted contract, matrix, predecessor schemas and existing private CALLS semantics remain untouched. The production identity delta is unaccepted; these are exact candidate bytes for independent review, not selected production authority.

## Canonical record policy and role domains

The whole-file schema ID is `https://jaresty.github.io/lsp-trace/schemas/adr0011-production-admission-v1.proposed.schema.json`; role URIs are that ID followed by `#/$defs/productionQueryDeclaration`, `#/$defs/productionDependencyInventory`, and `#/$defs/productionAdmissionFinal`. Independently pin the entire schema bytes and these exact role URIs before any implementation selection. A record is UTF-8 canonical JSON: object keys sorted by Unicode code point, no insignificant whitespace, integer decimals without exponent or leading zero, JSON-standard escaping with no alternative equivalent representations, no duplicate names, no floats, no invalid Unicode, and exactly one trailing-free JSON value. Reject any noncanonical original bytes even if parsed data validate. The schema establishes local shape; the host must check every cross-record identity and source fact independently. `format:uri` assertion requires a validator configured with a format checker. URI strings are absolute and canonicalized before freezing the host plan; no relative URI, fragment reinterpretation, or filesystem path alias is admitted. Selectors are single basename components, never paths.

Define `H(domain, body) = sha256(UTF8(domain) || 0x00 || canonical(body))`, rendered `sha256:` plus lowercase hex. For each record's `record_id`/`occurrence_id`/`inventory_id`, compute H over all canonical record fields except that ID; domains respectively `ADR0011_PRODUCTION_QUERY_DECLARATION_V1`, `ADR0011_PRODUCTION_DEPENDENCY_INVENTORY_V1`; the final has no embedded ID and uses `ADR0011_PRODUCTION_ADMISSION_FINAL_V1` for its externally retained role digest. For every record selector use `adr0011-<role-slug>-v1-<hex sha256(canonical complete record)>.json`, where role slugs are `production-query`, `production-inventory`, `production-final`. Store byte length and SHA-256 of complete original bytes in each external ref. A ref's `schema_version` is the full role URI for new roles or the independently pinned historical role URI for unchanged predecessors. A schema ref is not itself an authenticity claim.

The host-owned pre-invocation plan fixes all declaration fields, no caller or provider values choose expected identity; freeze and replay the plan before `documentSymbol` or `references`. `git_before.role=host_git_before`; declaration role is `production_query_declaration`. The declaration contains no post-invocation fields. Verify no-replace source/declaration publication, close, parent sync and exact readback before invoking either method. Reject missing, duplicate, changed or unverified declaration without fabricating a terminal or newly issued T/A.

The 21 final immediate role entries are exactly: candidate, proposal, events, scanner, raw_result, response_read, references_method_record, target_record, document_symbol_target_result, owner_read_symbol, owner_read_references, prepared_source, source_identity, revision_identity, host_git_before, host_git_after, policy_method, policy_admission, policy_privacy, policy_retention, production_query_declaration. Exactly one of each. Four policy refs name complete immutable method/admission/privacy/retention byte objects with independently pinned digests. The inventory is an ancillary validation witness bound by `context.inventory_id`, `inventory_digest`, `inventory_byte_length`, `inventory_selector`; it is never an immediate ref and cannot displace any entry. Each ref encoding is strict canonical JSON; sort the 21 encoded strings by unsigned UTF-8 byte order, once, then parse them back into final `dependency_refs`. Check exact role multiplicity separately, not by trusting the final or inventory. Symbol and references owner reads and BEFORE/AFTER Git observations have distinct role identities; reject swapping even when digests coincide. Require `context.a = context.p` and target admitted before final issuance; JSON Schema alone cannot assert these relations. Final context must match the independently frozen invocation, target, declaration, result and accounting. The final has no self-attested verification member; independently selected no-replace publication/readback proof and a fresh exact final readback are external replay preconditions, not a 22nd immediate ref. Verify all transitive predecessor bytes and role-specific identity pins, including original source/result and policies, before and after no-replace final publication. Final cannot self-reference; post-publication receipt/readback is external evidence, not a 22nd ref. Only private verified final may issue T=1,A=P; no ordinary raw disclosure.
