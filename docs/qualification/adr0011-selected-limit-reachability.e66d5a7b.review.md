# ADR0011 selected-limit reachability and allocation — frozen `e66d5a7b`

**FALSIFICATION PACKET, NOT QUALIFICATION OR A CONTRACT AMENDMENT.** Classification is relative to the named layer: `REACHABLE` means a valid input can reach its counting point, not that the selected edge/edge+1 pair has passed; `SHADOWED` means an earlier narrower guard rejects first; `UNREACHABLE_AT_THIS_LAYER` means this layer cannot construct that witness. This packet reads the frozen private source at `e66d5a7b`; subsequent test-only witnesses are identified separately. Production `PublishReferences` stays `nil,ErrChain`; matrix executions 0/162 and production T=A=0.

**Allocation requiring separate review before a frozen source edit:** Owner Manager response aggregate 4,194,304 bytes/four messages and staged request/response frames 2,097,152 each must be selected independently; `eligibleOwnedMethodRequest` and `buildOwnedMethodPair` currently enforce a separate 1 MiB request/response eligibility ceiling and must be reconciled before raising Owner's aggregate. The 4,194,304 framed request needs its own measured write guard. Preserve 65,536 exact params, 1,048,576 exact result, 1,500,000 canonical record and 1,048,576 scanner visits as distinct units. Raising `MaxBytes`/`frameCap` alone neither proves the lower caps nor makes an otherwise unreachable Owner fixture pass. Any source change invalidates the 90-file source pin until a new independent manifest review. A shadowed rejection never counts as a passed downstream bound.

**Post-freeze offline controls, not matrix executions:** `internal/adr0011methodresult/production_chain_limit_test.go` now tests exact canonical edge and +1; `cmd/lsp-trace/adr0011_calls_omission_baseline_test.go` pins the omitted-family CLI process response at 43,541 bytes, SHA-256 `d9630f80e4b8df33f345c8dfb52659b9813adeca5f884935d6dae680e39e95c5` from unchanged Program C source. An added `input_family:"CALLS_ONLY"` is rejected rather than silently ignored. Thus an **omitted-versus-explicit input-family byte pair cannot be run yet**: the explicit selector is not authorized/implemented. `relations:["CALLS"]` on slice is a different contract, not a surrogate. The process baseline is a compatibility guard for later additive-selector implementation, not a declaration that parity has passed.
