# B05 normalized-relation qualification

B05 qualifies the committed normalized-relation contract without implementing framework semantics in Go. The exact ledger is `internal/b05qualification/testdata/fixture-ledger.json`; the executable guard is `go test ./internal/b05qualification -count=1`; retained evidence is `qualification/retained/b05/qualification-evidence.json`.

## Nine fixture families

1. `plain_js_calls`: omitted relation selection remains graph-v3, server-reported `CALLS` only.
2. `ember_glimmer_chain`: records the motivating task, reload, state, yield, argument, render-read, and callback observations with exact expected non-CALLS kinds.
3. `callback_passage`: permits `PASSES_CALLBACK` and prohibits promotion to invocation.
4. `advertised_no_prepare`: records advertised capability, `PREPARE_RETURNED_NO_ITEM`, zero CALLS, and `UNKNOWN` completeness.
5. `unsupported_template`: records `ADAPTER_NOT_AVAILABLE`, never `NO_RELATIONS_WITHIN_BOUNDS`.
6. `mixed_revision`: rejects conflicting revisions and identifies the custody failure.
7. `bounds`: retains a deterministic frontier, phase receipt, and `PARTIAL` completeness.
8. `identity`: requires stable relation/node identities and logical digest under replay and traversal reorder.
9. `red_validation`: rejects mislabeled CALLS, callback-as-invocation, state-as-render, runtime claims, omitted revision, and false completeness.

Every family declares its observations, exact expected relations, prohibited claims, completeness, and revision policy. The ledger is qualification truth; it is not a source analyzer.

## Managed acceptance

`TestRealManagedIncomingAndSliceAcceptance` invokes the production `incomingops.NewExecutor` and `sliceops.NewExecutor` against one retained-generation runtime specimen. It requires graph-v3 CALLS-only compatibility and ensures no framework relation is synthesized by the managed Go path.

## Evidence authority

The retained B05 result is PASS only for the hermetic ledger and managed-executor acceptance. External adapter/provider support remains **BLOCKED** unless separately retained evidence is PASS. Unknown, unavailable, unsupported, failed, bounded, and empty outcomes are not interchangeable.

No B05 artifact establishes runtime execution, callback invocation from passage, repaint, feature identity, whole-source completeness, or relation absence from unknown evidence.

## Frame 6 production qualification

`qualification/retained/b05/qualification-matrix.v2.json` is the versioned aggregate for exactly ten immutable seeds: one positive and one confusable negative for each of `PASSES_CALLBACK`, `INVOKES_TASK`, `TRIGGERS_RELOAD`, `UPDATES_STATE`, and `RENDERS_FROM`. It retains exactly twenty attempt records, one `incoming` and one `slice` attempt per seed, and four stage results per relation.

Run `./scripts/qualify-b05-frame6.sh` to install pinned npm dependencies, independently pack and install the physical Ember/Glint provider, hash the package and executable, create a strict Git workspace, and run every attempt through the real `lsp-trace-mcp` stdio process with the managed fake-LSP substrate and `glimmer-js`/`ember` selectors. The Go runner validates generic process, envelope, custody, and replay behavior only; Ember semantic matching remains provider-local.

The provider advertises `PASSES_CALLBACK`, `UPDATES_STATE`, and `RENDERS_FROM`. `INVOKES_TASK` and `TRIGGERS_RELOAD` remain S1 `BLOCKED` and are not advertised. Therefore `PROGRAM_B_ADMITTED=false`: admission requires support for every requested relation. Confusable negatives are bounded to their frozen seed and never establish relation absence outside that boundary.

## Release gate

Run `./scripts/test-b05-qualification.sh`. It validates the committed artifacts, exact Frame 6 counts and outcomes, capability non-advertisement, executes the B05 package, and is invoked by `./scripts/release-check.sh`. Any failure blocks release.
