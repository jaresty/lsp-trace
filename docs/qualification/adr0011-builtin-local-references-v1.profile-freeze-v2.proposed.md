## Independent review and non-claims

Replay must compare actual target policy/schema complete original bytes to profile descriptors and recompute target implementation identity from an independently retained measurement original; schema-valid digest strings and the two synthetic tests do **not** do that at runtime. The tests now pin the target policy and whole schema bytes, show a schema-valid target-policy-digest substitution changes `plan_id` against a held synthetic selection, and keep the 20 historical + 1 production declaration role mapping. This remains a synthetic local discriminator, **not** an implemented verifier or real code measurement. Independent review should try a coherent rehash of target policy/schema/measurement/plan/selection against unchanged embedded profile bytes; inspect whether any field could be substituted without failing original-byte comparison. Also check that the reused historical target role URI stays unchanged, that target policy's exact semantics and selected limits are feasible, and that no target digest is inferred solely from references policy.

Separately challenge built-in selection and local product usability: profile defaults do not override the selected privacy policy's `capture_default:OFF` or `live_capture:EXPLICIT_PER_RUN`; an explicit future operation is not automatic consent for **currently unauthorized** live/raw retention. The root resolver and single-process exclusion remain proposed, unimplemented and fail-closed; `os.UserConfigDir`/known-sync checks can make an individual installation unavailable. An executable-file digest is not proof of a trusted build or running memory; no same-UID/host adversary resistance or cross-process lease is claimed. Profile V1→V2 and restart must replay exact prior originals or report unavailable, never use `latest`. The witness policy's declaration-ref is per-attempt and not self-selected. No lifecycle disposition is merged into Lane A.

Requested independent disposition: `ACCEPT_BUILTIN_PROFILE_FOR_PRIVATE_IMPLEMENTATION` or `REVISE` with the first concrete schema-valid counterexample. Even acceptance authorizes only the next **private/default-off** implementation design and tests, **not `owner.go` wiring by this packet**, public behavior, per-run live capture, rows 015–017, or production issuance. The final stays exactly 21 immediate refs with three ancillary inventory refs and a distinct attempt manifest. `PublishReferences` remains fail-closed, production/public T=A=0, references 0/162; definitions and lifecycle remain separate `REVISE` lanes, UX 0/14, no `ADR_0011_COMPLETE`.
