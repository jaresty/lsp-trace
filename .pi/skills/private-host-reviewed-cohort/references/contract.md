# Private cohort V1 contract

Explicit sibling CLI: `private-host-cohort prompts` (read-only compiled role contract), then `private-host-cohort preview|setup|run|fail|finalize REQUEST`; role helpers `ready MAILBOX ROLE LAUNCH_ID PROMPT_HASH`, `wait MAILBOX ROLE AFTER_SEQUENCE WAIT_MS`, `respond MAILBOX ROLE SEQUENCE` (stdin). No public help/MCP/default route is changed. Legacy V3.1 Task/Response/config/hash bytes remain unchanged.

Normative source: `cmd/lsp-trace/private_host_cohort.go`; `internal/privatehostproductv3/cohort*.go`. The canonical sibling request is `hostCohortRequest`: Schema=`private-existing-host-cohort-request.v1`, SourceRequest (absolute private canonical legacy source request), SourceRequestSHA256 (exact source-request bytes, including its separate runtime grant), RuntimeGrantSHA256, Configuration, BackendTimeoutMS. SourceRequest retains its separately caller-supplied runtime grant. The sibling grant hashes canonical JSON with RuntimeGrantSHA256 empty. Configuration is `CohortConfig`: Profile=`PRIVATE_EXISTING_HOST_REVIEWED_COHORT_V1`, Protocol=`PRIVATE_V3_REVIEWED_COHORT_1`, SourceConfigSHA256, ScopeSHA256, Requested, RolePromptSHA256 (exact compiled interpreter/reviewer prompt digests, available from `prompts`), Store (a separate disjoint private store), Grant (explicit supplied binding, not authentication), MaxCalls, MaxRequestBytes, MaxResponseBytes, MaxTotalBytes, MaxOutputBytes, Navigation (explicit optional boolean). These are ceilings, never unlimited defaults or new per-cohort grants.

Bounds: maximum ten own items per frame; actual encoded request <=1048576 bytes; physical response <=65536 bytes; cumulative calls <=16, request+response <=8388608 bytes, response output <=4194304 bytes. Corrections use the original totals. Packing measures actual canonical task frames plus the full bounded reviewer-response envelope; it does not count logical bodies as wire frames or duplicate a whole body as a hypothetical quote. Frames are exact direct UTF-8 JSON file contents: split part bytes concatenate exactly to request bytes; no base64 wrapper exists. Receipt/manifest export and ordinary host-tool outer envelopes are explicitly excluded, not equated with logical JSON or claimed fully accounted physical host traffic. A one-byte oversized response sentinel is retained/charged and refused; no success claims it is within the per-response bound.

`CohortTask`: Protocol, ConfigSHA256, Grant, Role, Stage, RequestDigest, Sequence, Items. Items bind ItemID/InputID/Target/Attempt/Grant/config/scope/prepared/checkpoint/four original raw references, complete own Body/OwnBodySHA256, Revision, Predecessor, Proposal and Review. Correction requests carry the exact rejected review as data, not only its digest. RequestDigest is the canonical task hash with RequestDigest empty. Initial revision is 1. One correction is revision 2 with exact prior reviewer-decision digest, predecessor attempt plus `/correction-1`, unchanged own source and previous proposal. Reviewer requests include the exact own-item interpreter proposal. Full raw graphs stay exact retained references, not all disclosed in the capsule; no inferred/union CALLS.

`CohortResponse`: Protocol, RequestDigest, Items (ordered array). Every item MUST contain all of: ItemID, InputID, Target, Attempt, Predecessor, OwnBodySHA256, Revision, Disposition, Label, Explanation, Alternative, Falsifier, Quote, Start, End. Exact decoded key names only; duplicate escaped keys, aliases, unknown nested fields, omitted/repeated/extra items, invalid UTF-8 and trailing JSON refuse before canonicalization. Whitespace and legitimate key order are accepted and physical bytes remain exact. Disposition is SUPPORTED, UNSUPPORTED, UNRESOLVED or WITHDRAWN. Label <=512 bytes, Explanation <=2048, Alternative/Falsifier <=512, Quote <=4096; all nonempty. Citation is an own-body UTF-8 byte range with 0<=Start<=End<=len(Body), checked BEFORE slicing or subtraction. Reviewer-supported narrowing is retained, unsupported items never become positive by default. A second failed review remains an explicit gap; all history remains visible.

Optional navigation uses a distinct `PRIVATE_V3_REVIEWED_COHORT_NAVIGATION_1` frame within this sibling profile, at most two remaining exchanges from the SAME cumulative grant. Its task contains Protocol, ConfigSHA256, Grant, Role, RequestDigest, Sequence, Candidates (current reviewed revision plus label/explanation/alternative/falsifier), Proposal. It contains summaries, not original bodies or all raw graphs. Response has Protocol, RequestDigest, Groups. Every group has ID, Label, Explanation, Alternative, Falsifier, Withdrawal, Revisit (nonempty <=1024 bytes), Members (2–10 unique exact ItemID/Revision/ReviewSHA256 triples), Supported (boolean). At most ten groups. Review must return every proposed group in order with the same exact members; it may narrow explanations or leave support false. All hypotheses and prior proposals remain visible; no feature identity/confidence/stability is accepted. Insufficient remaining budget records UNAVAILABLE_REMAINING_GRANT without creating a new grant or spending a partial optional pass. The controlled twenty-body fixture includes one correction plus grouping/review in eight exchanges.

Durability: closed private 0700 store, 0600 regular single-link files, bounded 4 MiB progress/report field graph. Create-only whole-cohort claim and cumulative reservation snapshot precede backend disclosure. Raw reply and backend-return receipt are spent before parse. Crash recovery reconstructs bounded physical spending even when a reply/receipt became durable before the next counter snapshot; the final in-flight reply is not adopted as semantics. Recovery never invokes a backend or refunds a claimed generation. Lost/ambiguous responses cannot be auto-retried after restart. Immutable versioned states preserve validated item history. Two exact machine and two regenerated human views must all be distinct inodes/private/single-link before paths are called paired. The sibling prior selector replays Cohort claims, raw replies and own revision lineage, not legacy flat Response. Bad later views remain immutable UNKNOWN and earlier validated rows may survive qualified failure. Same-user consistent full-history forgery remains unauthenticated.

Host termination: terminal publication is separate from role returns. Every parent runtime exit attempts terminal; publication errors are surfaced. Roles wait with deadlines; parent uses actual ordinary tool completion notifications and retrieves results only after completion. `CohortRoleReturn` fields: Kind (`HOST_OBSERVED` or test-only `SCRIPTED_CONTRACT`), Role, LaunchID, TerminalSHA256, Status (`RETURNED`), ReturnSHA256, Sequence. Finalize requires terminal/report binding and both distinct ready-role IDs, and creates a separate immutable `host-returns.json` linked to exact report paths/digests. It does not rewrite the report or authenticate/isolate a producer. Original inner cleanup, outer child-process Wait and host-role returns are three separate fields.

Next part, not delivered here: arbitrary-total source/application-unit/manifest/report streaming, removing the existing 4 MiB whole-prefix cap, whole-application durable accounting and practical amplification measurement. Original acquisition/session, separately supplied bootstrap retries, inference billing, ordinary host/export framing and complete report/store IO remain excluded. No arbitrary-total or actual-model usefulness/latency claim follows from controlled twenty-target fixtures.
