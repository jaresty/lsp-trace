# Algorithm

Validate attempt, deterministic execution-control, policy, limits, pins, and source associations. Poll deterministic controls at fixed points. Admit associated source inputs through the pinned source-admission v2 semantics. Search exact query bytes at every byte offset, preserving overlaps. Emit byte ranges, LSP line/UTF-16 half-open ranges, exact accounting, custody, replay, and a non-executed RANGE_UNION candidate only on success.
