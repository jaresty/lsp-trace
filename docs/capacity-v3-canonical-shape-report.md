## Exact authority change

Before:
1. DTO JSON tags supplied convenience encoding/assignment; encoding/json accepted case-insensitive aliases.
2. Decoder maintained independent required/non-null key lists for root and metrics, but did not reject additional case-variant names before assignment.
3. Hand-maintained V3 JSON Schema independently supplied exact fields, requiredness, enums, ranges and reason/metrics branches.
4. The existing semantic validator enforced STOP/retry=false, reasons/units, dimension constraints and equations.

After:
1. `internal/capacitydiagnostic/shape.go` is the **single maintained wire-shape authority**. Its local descriptors supply exact names, requiredness, scalar constants/enums/ranges and nested metrics. The same reason branches control required/forbidden metrics and generate JSON Schema `oneOf`; unit enum values are derived from those branches.
2. Decoder ordering is unchanged length limit and `strictjson.RejectDuplicates` first, then exact raw descriptor admission, then DTO assignment, then the unchanged `ValidateCapacityDiagnostic`. Duplicate decoded names, including unicode-escaped duplicates, and noncanonical aliases are rejected before Go assignment. The independent required-key maps were removed.
3. The committed JSON Schema is generated deterministically from the descriptor. Existing embedding, family registration, schema ID and public V3 meaning are retained. There is no V4. DTO tags remain convenience, not admission authority.
4. The one existing semantic validator and composed schema dispatch remain unchanged. Semantic dimension checks intentionally remain there; they are not a second independently maintained wire-field list.

The local descriptor is not a repository-wide validation framework. Runtime decoding needs no source-file reads, network access or runtime schema compiler. Generation uses only the already available Go toolchain and standard library. Command from repository root:

```sh
GOPROXY=off GOSUMDB=off GOTOOLCHAIN=local GOTELEMETRY=off go generate ./internal/capacitydiagnostic
```

`TestCapacityShapePublication` compares generated bytes with the existing embedded registry publication. Two regeneration reruns left the schema SHA-256 exactly `eb4ae29fe1b5970c48c141fe3dfffb491d201f5e537632778350ccf29dcda806`.

## Wire versus standalone structural validation

Full-contract validation means `DecodeCapacityDiagnostic` or `schema.ValidateFor(..., FamilyCensusCapacityDiagnostic, "v3")`. A standalone JSON Schema sees a parsed instance, not duplicate raw names or input byte count, and cannot enforce sibling arithmetic. The unchanged uint64 decoder also retains its existing integer wire spelling restrictions; the schema describes mathematical integers rather than those lexical restrictions. Trailing JSON is a parser rejection, not an arithmetic/schema claim.

The shared deterministic corpus now separately checks both full entry points and standalone structural classification for every parseable case, after ordinary JSON parsing. Explicitly classified standalone limitations: identical/escaped duplicate names collapsed by parsing, oversized whitespace, and sibling arithmetic. No fake standalone/full-contract parity is claimed.
