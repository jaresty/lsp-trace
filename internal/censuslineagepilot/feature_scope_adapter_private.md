# Private retained-scope adapter qualification

This package-local adapter has no CLI/MCP dispatcher, schema registration or real invocation entrypoint. Constructor input is the opaque successful read-only `scopeRestartResult`, an actual Manager, exact initialized session ID/generation, and the caller's existing lease context. Zero/inconsistent results are refused through retained plan/manifest/metadata/head invariants. It neither reopens retained roots nor writes retained objects.

Construction prepares all six exact retained URIs as Go documents with `CaptureSupply=true`. Both returned document identity and independent supply (including exact notification identity/version/content) must agree before binding. Cached captured supplies are accepted only when nonnil. Manager rechecks its independent copies under lock at bind and on every guarded transaction. Roles come from retained records: four nominations and two context-only members. Selection/partition plan are canonically rederived (fixed size two); no enumeration or mutable selector is accepted.

After binding, the supplier only verifies exact frozen nomination membership and calls `CheckRetainedScopePrivate`, which performs no filesystem or transport work. DocumentSymbols, prepare, incoming and outgoing all attach the same opaque guard before Manager RoundTrip. Native acquisition receives a WireClient with the same guarded closure and a frozen verification-only supplier. A private wrapper keeps the entire WireClient method, including all post-callback validation, inside the adapter's admission mutex. Full supported call items, including opaque data, are preserved. The WireClient directional callback is deliberately absent: directional custody requests explicitly refuse instead of converting ordinary results into leases. No historical method-pair/frame eligibility is widened. Guard JSON serialization refuses.

## Fixed independent bounds

- All pre-supply work and subsequent adapter use: 30-second lifetime, shortened by caller context/lease cancellation.
- Each semantic transaction: at most 5 seconds, shortened by adapter lifetime and the actual caller context deadline. Native acquisition carries its request/global timeout through that context; WireRequest/AcquisitionContext do not add a separate deadline field. Manager receives the intersected deadline explicitly.
- Params: 2 MiB (also independently checked by Manager).
- Result payload ceiling: 2 MiB per response, independently limited by remaining admitted-result capacity. This is not the native wire-body budget.
- Private wire-body ceiling: 2 MiB + 1 KiB. Direct calls retain their fixed defaults: `min(2 MiB, remaining admitted-result capacity) + 1 KiB` wire bytes and message-class ceiling 64. The direct-only envelope allowance is not extra admitted result capacity.
- Native WireRequest limits must both be positive. Manager receives `min(native MaxMessages, 64)` and `min(native MaxBytes, private wire-body ceiling, remaining admitted-result capacity)`. No envelope bytes are ever added to declared native MaxBytes. Larger supported positive limits tighten to private ceilings; zero/negative bounds refuse before transport. Budgets below the smallest representable successful JSON-RPC response body also refuse before transport, including byte=1; there is no silent inflation.
- Manager MaxMessages retains its existing per-provider-message-class meaning (notification and control classes), not a combined total-message promise. One notification plus one response fits MaxMessages=1; two notifications plus a response distinguish limits 1 and 2.
- Aggregate returned result bytes: 8 MiB; at most 256 semantic attempts, shared across discovery/native use. No owned/frame capture opt-ins.
- Discovery: exactly four static source files, 128 symbols, depth 64, 1 MiB symbol strings. The retained six-file policy remains 2 MiB/file and 8 MiB total, but Manager's existing capture-supply ceiling is independently 1 MiB/document and is not raised here.

Failures return without restart/retry. Manager lifecycle, poison, lease and cancellation rules remain authoritative. Returning from a lease retires that guard's lease identity; the adapter must not be reused in another lease. Every complete invocation is serialized by a separate admission mutex through Manager transport, aggregate accounting, shared predecode validation, and direct/native typed decoding. Manager's transport exclusivity alone is not used as an aggregate reservation. Every consumed response that fits the payload and remaining-result ceilings is charged before shape/decode checks; admitted charge is never refunded. Any wire transaction failure, or any duplicate/shape/decode/range/response-size error after consuming a response, permanently latches the adapter terminal, including errors from WireClient after the transport callback returns. Oversized/unavailable transport responses also make the adapter terminal, without admitting bytes beyond the result ceiling. Subsequent invocations issue no semantic requests. Harmless pre-write refusals such as missing native coordinator context and directional-custody refusal can remain nonterminal. No retry or allowance reuse follows a terminal error. Manager's closed failure code is retained in a private typed error; wire-budget RESOURCE_EXHAUSTED is not relabeled as a parser failure, and no generation restart occurs.

Ordinary Manager byte enforcement is its existing cumulative complete-message body-byte policy. An over-budget complete frame can be consumed before Manager reports RESOURCE_EXHAUSTED. Forwarding native wire bounds fixes admission/failure enforcement; it does not introduce a hard physical-read or public untrusted-allocation bound. Fake-transport tests instrument actual stdout bytes separately and distinguish zero-byte pre-transport refusal from bounded consumed-frame failures. Global Manager framing/eligibility behavior is unchanged.

## Private response contract

Both direct and native paths run the same bounded predecode validator before any response normalization. It enforces JSON nesting at most 128, duplicate rejection, exact protocol keys, required non-null fields and uint32 coordinates, ordered ranges, selection-range containment, correct incoming `from` versus outgoing `to`, and present non-null `fromRanges` arrays. Zero coordinates are valid; absent/null coordinates are not. Opaque item.data survives unchanged as a supported JSON value (not raw-frame custody); keys inside data are not reinterpreted as protocol aliases. Result `null` and `[]` retain distinct direct/native method results.

Document symbols never use the global custom lsp.DocumentSymbol unmarshal. An adapter-local normalizer preserves valid unmixed hierarchical symbols (including children/detail) and local flat SymbolInformation (including containerName and observed LocationURI). The native path also runs the existing WireClient validator; its successful symbols use the same private normalization so supported fields do not silently disappear. Symbol tags/deprecated and unsupported/unknown fields are refused on exact presence, even zero/false/empty values, because the existing symbol result type cannot represent them. Historical WireClient/global LSP behavior is unchanged.

Flat observations whose location URI differs from the exact requested nomination URI are omitted, never relabeled. The opaque binding observation exposes a private omission count; Discover marks closure unknown/complete=false and reports its invocation's known omitted observations. Native callers must consult the binding observation rather than interpreting filtered symbols as source closure. Context-only locations are equally ineligible for nomination. Mixed flat/hierarchical responses refuse rather than normalizing ambiguous forms.

Endpoint responses remain server observations, including external frontier endpoints; they do not authorize external source preparation or context nomination.

## Qualification boundary and missing bridge

Disposable fixtures reconstruct exact retained input using the real read-only reader, then exercise actual shared Manager admission with fake stdin/stdout transport. They do not invoke a real language server or write real retained data. Coverage includes cached capture, mismatches and zero state, six-before-semantics ordering, four/two accounting, deleted checkout after bind, supplier no-write, shared unguarded refusal, external refusal, native ordinary calls, explicit directional refusal, cancellation, poison/no retry, and retired lease. Companion Manager tests check every member's version/language/supply-generation drift without wire work. Review regressions additionally cover external/context flat locations, local flat/hierarchical preservation, malformed preparation/coordinates/ranges, explicit unsupported symbol fields, duplicate JSON, incoming/outgoing reference shape, native validation inside complete invocation admission, Manager-enforced native wire-byte and per-class message-limit failures, exact wire-body equality, exact 2 MiB direct result success and plus-one refusal, null versus empty calls, and terminal no-further-request counts. Tables cover lower/equal/oversized/invalid wire limits, aggregate remainder, and deadline intersection. The shared native callback/locked helper is exercised with an actual Manager, including zero-byte invalid-bound refusals and authoritative consumed-limit failures. A controlled fake-transport barrier pauses after Manager releases transport ownership but before response admission. A second positive handshake reaches invoke's actual lock-attempt seam; a TryLock ownership witness—not a short negative sleep—establishes exclusion through accounting/validation. The next response sees reduced remaining allowance, and admitted aggregate bytes never exceed 8 MiB. Only positive-progress watchdogs use timing. This is a private API qualification, not a public untrusted-allocation bound.

Still missing: scoped native completion and availability dispositions bound to this scope/session/guard, their custody-safe transfer into the Program C profile/composition, and the accepted scoped receipt bridge. D, references and caller-occurrence requirements remain separate and unqualified. No complete pipeline, analyzed-source identity, source closure, custody receipt or accepted feature identity is claimed. An independent adapter review is required before any next live pilot.
