# ADR0011 architecture B: immutable admitted-relation index (proposal)

Real Go/gopls references qualification against the 162-row matrix and a separate `QUALIFIED` decision precede any references index build. Separately qualified definition occurrences, accepted endpoint identity and grouping policies precede definition edges, mixed/no-CALLS grouping, or Leiden. Production T=A=0; authority 0, accepted false, completeness UNKNOWN.

A later index version binds a sorted, immutable ledger of *already admitted* typed relation occurrences to exact receipt digests, lengths, family/version, source/revision and endpoint-resolver policy. Retain original kind, direction, ordinal, multiplicity and tombstone status; equal endpoints are not equal occurrences. Store forward and reverse adjacency over the **same** occurrence identities; reverse pointers are not inferred inverse LSP results. Build once at an explicit admitted-ledger publication, with bounded work, no-replace write, exact readback and immutable digest. Missing, revoked or mismatched dependencies fail before publication; never derive this from a claimant or synthetic receipt.

An ordinary bounded walk receives only an immutable index handle and budgets: no session, LSP, filesystem, source resolver, ledger hydration, replay or index builder. Seed verified endpoint IDs; account for outgoing/down-depth and incoming/up-depth, combined node/occurrence/frontier limits, skipped kinds and unavailable inverses. A missing index or absent inverse is unavailable/UNKNOWN, never an empty or silently rebuilt neighborhood. Select D/R through an additive versioned contract; omission preserves exact historical `CALLS_ONLY` bytes and remains on the existing slicer. Keep the existing CALLS-specific Program C admission unchanged. A separately qualified grouping-policy receipt must match the index input digest before mapping typed occurrences to `PairWeight` and invoking Leiden.

Falsify by substituting one receipt, resolver, ordinal, kind, direction, revision or tombstone; preserve parallel equal-endpoint occurrences and reverse-only paths under node/depth limits; test stale/missing snapshots. Instrument warm repeated/concurrent walks with panic-on-use acquisition, LSP, I/O, hydration, replay and rebuild dependencies. Measure separately admission-time build time/bytes and warm walk nodes/edges/allocations/latency at depths 1/2/4 and tight budgets, with zero ordinary-walk I/O.
