# ADR0011 generic LSP finite limits — proposed decision packet

Status: **PROPOSED / ACCEPT_READ_ONLY_GENERIC_FINITE_LIMITS_PACKET requested**, not accepted enforcement. Scope: generic successor only; no pinned schema URI, policy digest, provider pin, qualification claim, public surface, executable change, or minted identity. Parent independent reviewer must accept/revise this packet before identity minting. Numeric choices below are candidates, not assertions that runtime enforces them. Units are bytes (not Unicode code points), counts, or monotonic elapsed time. Exactly-at-cap succeeds if otherwise valid; cap+1 fails without partial admission. No cap silently defaults to unlimited.

## Evidence boundary and observed seams

`internal/lspwire/wire.go:28-40,143-186` supplies configurable body/header limits (currently defaults 16 MiB/64 KiB), but `bufio.Reader.ReadString('\n')` allocates an entire newline-free line *before* checking `MaxHeaderBytes`; the header cap is thus not a preallocation bound. `internal/lspwire/read_frame.go:74-77` expressly bounds retained raw copies, not reading/allocation. `sessionruntime/sessionruntime.go:721-749,835-885,903-922` defaults message count to one, inherits body budget, applies a deadline, reads one decoded message at a time, and accumulates **reserialized** `json.Marshal(message)` bytes after reading; these are not exact cumulative inbound wire bytes. Method-frame capture is opt-in and does not enforce a generic frame cap. `internal/adr0011acquisition/owner_read.go:262-281` validates retained private V1 references by bounded readback/replay, not initial reader enforcement. `internal/adr0011builtinprofile/originals/target-schema-v1.json:64-77` pins V1 result and record maxima; do not edit it. `internal/adr0011lifecycle/partial_replay.go:25-30` and `v2_publication.go:137-199` have distinct legacy replay/readback limits. These observations are localized, not proof of completeness of all runtime paths.

All unrelated budgets are set higher than actual consumption, **except fixed upstream ceilings**, which must be respected. When equality cannot fit a fixed earlier ceiling, mark the row unobservable and first add a test-only injection seam at the named owner, never weaken production guards. A counted unit is charged before allocation/admission; overflow uses checked arithmetic. Distinguish messages received, including notifications and unmatched responses, from one selected result. ## Proposed admission rank and failure taxonomy

Assumption: one failed transaction may cross several budgets. Proposed earliest **causal** failure wins: (1) exact session/generation/lifecycle preflight and cancellation; (2) deadline before blocking operation; (3) bounded header read, syntax and declared body/frame bound before body allocation; (4) incremental cumulative bytes and per-frame JSON validity; (5) count each inbound message before dispatch, then match wire ID; (6) re-marshaled decoded-message accounting for every inbound message, then original encoded result-slice byte check for the matched response before candidate materialization; (7) source/executable acquisition bytes, allocation/work and object/event counters at each charge; (8) atomic private retention budget and access window before returning a retained selector. Earlier-independent errors are not relabeled as a later quota. A malformed length is `INVALID_FRAME`; EOF on a short header/body is `TRUNCATED_FRAME`; header, frame, body, result, cumulative, messages, allocation, work, source, executable, objects, events and retention-byte caps are `RESOURCE_EXHAUSTED` with a private bounded subreason identifying only the dimension; deadline is `REQUEST_TIMEOUT` or `TRANSACTION_TIMEOUT`; expiry is `RETAINED_ACCESS_EXPIRED`; stale generation/lifecycle conflict/cancellation retain their existing distinct types. Never return partially admitted result, events or retained selector at failure. Avoid raw URI, path, JSON, server error or bytes in public failures. Collision fixtures force two thresholds on one byte and assert the earliest actual check with recorded counters; rank is not a license to predict a cause not reached.

## Compatibility and pause

V1 method markers remain distinct: `textDocument/references` belongs to the references method record, while target selection remains `textDocument/documentSymbol`; do not rewrite V1 refs, pinned schema/policy bytes, target records, raw offsets, retention records, or historical artifacts. A successor can cite retained V1 references read-only by exact selector/digest and role without interpreting its old maximum as new enforcement. Fresh readback independently reopens and verifies bytes; capture alone is neither readback nor admission. A new finite window affects only successor owner access; V1 remains governed by its own policy. Lifecycle D remains **paused** until the parent separately accepts a successor implementation contract, demonstrates at-cap/+1 isolation (including stated gaps repaired), and explicitly authorizes identity minting. This packet does not resume D, deploy, qualify, or publish.

## Model interpretation

This packet treats all numbers as proposed successor budgets and preserves current limits as observations, not proof of enforcement. Assumptions: synthetic fake servers and clocks can be added only in a later authorized implementation; exact body/result slicing is available only after bounded decode. Gaps: header preallocation, aggregate exact wire charging, allocation/work instrumentation, and retention access control. Verification: independent review of shadowing; fresh readback test; at-cap/+1 fake-server matrix. Improved framing: accept numerical policy and its observable test architecture separately from any future runtime authority.
