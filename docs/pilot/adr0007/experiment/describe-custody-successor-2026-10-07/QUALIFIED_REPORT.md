# ADR 0007 Describe bounded qualification

- Policy: post-run stakeholder threshold amendment
- Custody: **96/96 selected attempts committed**
- Critical evidence and ceiling checks: **48/48 pass**
- Case replay agreement: **22/24 (91.7%)**
- Required case threshold: **90%**
- Replay-only limitations: `item-09, item-14`

Qualification is bounded semantic usefulness, not feature identity, completeness, authority, public enablement, Search qualification, or Group qualification.
