# Retained partial Program C — private fixture-qualified consumer

## Import and admission boundary

`retainedpartialprogramc -> censuslineagepilot + programc`. Neither lower package
imports the adapter. No operation identity, acquisition authority, or public
transport package is extracted or changed.

- `pilot.DerivedRetainedPartialNativePrivate` aliases the existing opaque producer
  result. Only successful `DeriveRetainedPartialNativePrivate` creates its private
  self-bound seal. Copies share immutable state; zero/decoded DTOs cannot mint it.
- `pilot.ReadDerivedRetainedPartialNativePrivate` checks the exact producer seal
  and returns cloned bytes, not a Program C permit. The existing parser remains
  consistency-only and cannot create this handle.
- `retainedpartialprogramc.Project(concreteProof)` checks that seal **before** the
  closed parser. The parser recomputes all eight record references, qualification
  proof, provider/code/seed/policy/scope bindings, original/derived graph digests,
  source statuses and withheld counts. The adapter then checks its fixed private
  ceilings, native semantics, projected node/occurrence/relation counts, and
  observed provider. It returns an opaque immutable `Projection`.
- `Compute(proof, seed)` or `ComputeProjection(opaqueProjection, seed)` invokes
  the existing Program C mathematics and returns a new private `Outcome` only.
  No raw bytes, generic interface, callback or caller-supplied source-binding
  constructor can enter this admission path.

## Shared mathematics is not admission

`programc.ProjectNativeCallsMathPrivate` validates native V5 schema/semantics and
calls the same unexported CALLS projection helper used by ordinary `Project`.
`PartitionCallsMathPrivate` checks canonical lexical nodes, strict numeric indices,
unique occurrence identities, unit weights, call-site ranges and exact directed
pair sums, including finite positive weights, before the shared unexported Leiden
implementation. These APIs return only detached numerical projection/partition
results: **no SourceBinding, authority, admission, profile or claim ceiling**.
They can operate on caller-supplied numerical data without promoting its origin.
They are not an ordinary `Outcome` constructor.

Ordinary `Project` still begins with Graph Provenance V5 admission; ordinary
`Compute`, composite admission, calls-v1 profile/digest, occurrence identities,
Leiden algorithm/resolution/seed handling and canonical logical digest are
unchanged. There is one CALLS interpretation and one Leiden implementation.
The math seam has 10,000-node, 100,000-occurrence and 8 MiB native-input caps;
resource/invalid-input failures are distinct from valid `EMPTY` partition results.

## Private output and source ceilings

Private profile: `DERIVED_RETAINED_PARTIAL_CALLS_PRIVATE_V1`. Its digest commits
the exported exact `ProfileDefinition` string; it is distinct from ordinary
calls-v1 pins. `Outcome.Math` contains outcome, algorithm, resolution, seed,
canonical communities and logical digest; the logical digest commits communities,
not source custody or semantic purpose. `Outcome.Projection` contains only direct
observed CALLS occurrences and directed pair reference counts.

The private `SourceBinding` exposes exact detached input/native bytes and a detached
full original input manifest. This retains typed native process context, seeds,
frontiers, policy, original eight record references, source read caps/counts,
caller-asserted code pin and observed provider identity without inventing receipts.
Native semantic receipt validity commits native semantics, not source authority.

`PRIVATE_COMPUTATION_QUALIFIED` is the **adapter's** private computation disposition.
The producer input manifest remains `NOT_PROGRAM_C_ADMITTED`. Neither status
changes the other object. Every private result retains authority=0, accepted=false,
partial=true, source completeness=UNKNOWN, feature identity=UNRESOLVED,
canonical_complete=false, replay=false and original NativeV5 identity=false.
Graph-wide custody and ordinary native qualification receipts are explicitly
`UNAVAILABLE`. A real retained qualification ID is recorded in the manifest;
it is not relabeled as an ordinary native capture or graph-wide custody receipt.

Typed CALLS support reference counts and structural partitioning, not semantic
purpose, feature identity, runtime execution, complete inventory, whole-source
coverage, authenticated provider identity, production permission or authority.

## Owned fixture verification and remaining work

The integration test runs in `censuslineagepilot_test` (external test package) so
it can use the existing test exports without a production import cycle. It uses
the actual owned 25-target, eight-record capture/retention/qualifier/derived producer,
then runs the adapter **after every borrowed retention root has closed**. Default
and non-default process context are exercised. The fixture has 27 nodes, 3 CALLS,
3 occurrences, a withheld source and partial frontiers. For seed 42/resolution 1,
the actual existing algorithm returns 27 singleton communities. This is a computed
fixture partition, not an asserted semantic grouping; no graph is altered to
force non-singleton output. Repeated computation within the same fixture has an
identical canonical partition/digest and does not change acquisition/preparation
traffic. Temporary fixture paths change identities across independent runs, so
cross-run logical digests are not a fixed historical capture pin.

A separate compatible ordinary admitted synthetic fixture compares occurrence
identities, provider metadata, pair weights, canonical communities and digest with
the pure math seam. No private withheld carrier is rewrapped as ordinary V2/V5.
Other guards cover empty/resource distinction, malformed numerical projections,
zero/decoded handles/projections, all eight record substitutions, policy/seed/
native/provider/code/lineage mutation, detached accessors/outcome cloning, distinct
profile pins and ordinary envelope rejection.

This unit does no historical Program C execution, live calls, source opens,
Manager/reservation checks, replay, claim recovery, retention writes or publication.
Owned fixture setup alone performs its existing synthetic capture/retention.
There is no general driver, CAS integration or new full-pipeline Census receipt.
Authoritative plan bridging, instability and broader workflow qualification remain
pending, followed by independent review and parent integration before real input.
