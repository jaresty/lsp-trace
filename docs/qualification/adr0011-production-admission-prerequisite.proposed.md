# ADR 0011 — production admission prerequisite (proposed, not implemented)

**Decision sought: implementation-only review.** This packet does not enable production issuance or execute a matrix row. The accepted references occurrence contract and 162-row matrix remain byte-unchanged. Production/public `T=A=0` and `PublishReferences` fail-closed until separately reviewed implementation and occurrence qualification. No index, definition implementation, grouping or public selector follows.

## Owner and exact selection

A host-owned, default-off production admission boundary must choose the publication root, source/implementation identity, complete successor schema role map, four policy byte pins, session and registered workspace, and positive resource limits **before** invoking a provider. No caller-supplied manifest, schema ID, root, raw response, receipt, query-target or final record may select expected identities. Record the complete production selection as immutable evidence and verify it independently on replay. The existing 90-file `sha256:b06eca5f8b40b96eee624e932e39c215144a7e2c14162e05cd5896eb83bf475c` is only a synthetic source-byte pin; a production review must choose and verify its own complete implementation closure without claiming binary or provider authentication from a source hash.

The production owner requires exact managed READY Go/gopls in a registered clean Git worktree at one pinned commit, exact URI/position and predeclared occurrence identity. It independently checks prepared document bytes, digest, version and negotiated encoding, host Git root/commit/cleanliness before declaration and after capture, and the identity of both observations. The host acquisition owner issues a versioned immutable **query-occurrence declaration** before either method invocation from a host-predeclared exact workspace/URI/point, source/version/encoding, session/generation, revision and invocation identity. The declaration has a closed canonical field set, role-domain digest, no-replace selector, exact readback and independently selected expected inputs from the host plan; replay checks every field and its original bytes against that plan before allowing invocation. An arbitrary caller's candidate or response-derived declaration cannot establish admission. Here “independently admitted query occurrence” means this separately verified pre-invocation declaration, **not** an admitted references or target occurrence; it cannot be inferred from a later result. Missing, duplicate, changed or unverifiable declaration fails before invocation, with no fabricated terminal and newly issued `T=A=0`.

## Two linked transactions

1. **Document-symbol target:** The owner issues one keyed, bounded `textDocument/documentSymbol` request. Retain exact request/response identities, selected raw spans, complete result presence and bytes, source/version/encoding/revision and method-policy identities. Use the exact closed selection predicate modeled by `SelectDocumentSymbolCandidateV1`: strictly decode and validate the **entire** bounded hierarchical document-symbol array, reject duplicate/unknown required members and invalid ranges, require each `selectionRange` inside its display `range` and each child display range inside its parent display range, and count all symbols whose half-open `selectionRange` contains the negotiated-encoding query point (`start <= point < end`, lexicographic line/character). **Exactly one** containing selection range is required. Zero or two or more matches (including duplicates, nested matches or equal ranges) are unresolved; no display-range specificity ranking, name, provider order or references-returned location breaks a tie. Recompute the count and winner identity from the complete original result on replay. This predicate is a prospective production requirement based on the private selector, not a claim that its current candidate is admitted. Missing/ambiguous selection yields `TARGET_IDENTITY_UNRESOLVED` before references invocation; malformed or partial document-symbol response produces no target and the applicable closed method failure/diagnostic disposition, never a success target or an invented references terminal. Privacy denial is `WITHHELD` only for an explicit selected policy prohibition; uncaptured, missing or unreplayable evidence is `INCOMPLETE`. This implementation packet must bind the exact previously accepted containment comparator; it does not introduce a new tie-breaker. Publish and independently replay a complete immutable target receipt before selecting it as the references prerequisite. A test-owned private target is not an independently admitted production target.
2. **References:** Bind one distinct generation-scoped key and collision-safe invocation ID to exact raw params, method, declared query, admitted target ref, matched completed write/read, exact result presence/length/digest, and both Git observations. Reject key reuse, changed method/params/URI/point, target inversion, generation restart, or response without a matching write. Whole-result parsing, per-element terminal accounting, equal-location ordinal identities and limits are separately replayed; malformed prefixes have `P=A=0` even if individually diagnostic.

Both transactions require no-replace original-byte publication, exact readback, policy/schema and independently selected implementation pins, and a closed typed terminal journal. The final occurrence ledger uses a closed **21-entry immediate-ref inventory V1**, following the private final's fixed roles but replacing its test-only declaration role with a separately versioned production query-declaration role: candidate (1), proposal (1), events (1), scanner (1), raw result (1), response read (1), references method record (1), target record (1), document-symbol target result (1), owner read (2: symbol and references), prepared source (1), source identity (1), revision identity (1), host Git (2: BEFORE and AFTER), policy record (4: method, admission, privacy, retention in that order), and production query declaration (1). The count is 21; no optional, repeated or unknown immediate role is admitted. Encode each ref with exact role/schema version, selector and digest under the selected successor schema; sort the complete canonical encoded ref strings lexicographically exactly once for the final `dependency_refs` array, while checking the unsorted role/multiplicity inventory independently. Every immediate ref's canonical record recursively binds exact byte length/digest and its own required predecessor refs, including the four complete policy byte objects and original method/source/result bodies; replay the **transitive** closure, not only the 21 final refs. Recompute the inventory from independently selected owner inputs and the observed graph; reject omitted, extra, duplicated, reordered, mixed-schema, wrong-role or unreachable entries even when remaining hashes agree. Publication receipts/readback are separately required verification evidence, not invented additional immediate refs. Verify **every** retained dependency by reading original bytes and recomputing canonical identities before final publication; repeat complete closure replay and fresh final readback after publication. The final object must not self-depend; its post-publication readback is checked separately. Missing, changed, mixed predecessor/successor or committed-but-unverified evidence is non-issuable. A typed receipt is returned only after verification; no public raw bytes, source or private selectors leak in ordinary responses.

## Implementation falsifiers and stop condition

Use one writer after an exact seam plan; retain the default-off production constructor while implementing independently selectable private production-mode inputs. Do not wire a public selector or change accepted bytes as a shortcut. Required named RED/GREEN controls include: missing/mismatched query declaration before invocation; unique versus ambiguous target; exact keyed document-symbol/references write/read and two equal-location ordinals; all one-field substitutions; generation restart; source and Git changes before/after; policy/schema pin mismatch; missing raw dependency; mixed predecessor/successor closure; precommit versus committed-unverified publication; postcommit deletion; replay after restart; bounded success `T=1,A=P` **only after** fresh final readback. Preserve historical public RED tests until a separate authorized production enablement decision; no test-owned synthetic result is counted as live occurrence qualification.

**Independent implementation-only review requires:** exact source/schema/policy selection and frozen hashes, code diff, executable tests and retained original/readback/replay artifacts, paired negative controls including each omitted inventory role, proof production remains default-off, and a reviewer decision `ACCEPT_PRODUCTION_ADMISSION_PREREQUISITE_FOR_IMPLEMENTATION_ONLY` or `REVISE`. Even ACCEPT is not `QUALIFIED`, does not enable the production path, and cannot authorize rows 015–017. A separate reviewed production-enablement decision is required after implementation-only acceptance and occurrence qualification.
