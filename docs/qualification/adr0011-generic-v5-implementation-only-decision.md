# ADR0011 generic V5 implementation-only contract decision

**Disposition: `ACCEPT_GENERIC_LSP_CAPABILITY_EXCHANGE_V5_FOR_IMPLEMENTATION_ONLY`**

The accepted contract is the unchanged 11-path candidate identified by `.pi/evidence/adr0011-generic-v5-raw-id-review/SNAPSHOT.sha256` (manifest SHA-256 `b3bedbb010d0d46d29fff8f16a6aa2f91182f4bff47f284b38afff7644eaab5d`), read with the accepted read-only ownership matrix `docs/qualification/adr0011-generic-v5-enforcement-ownership.matrix.proposed.md` (SHA-256 `9c93213315644d30316f8f3893e7d1e9864023b8f38b5bc06ee5ca1d839f21d1`). Both independent read-only contract reviews found no incompatible immutable clause; the parent reverified all 11 paths, 54 offline vectors, and focused V5 Go tests. This decision does not change an original, identity, selector fixture, or historical manifest.

Schema permissiveness is not semantic authorization: a schema-valid null error-response ID cannot establish matching correspondence and must fail before state evaluation. Python acceptance of an oversized complete frame and Go's body-only frame bound are C implementation/coverage defects, not contradictions in the immutable V5 policy. The first failed-review V4 manifest file survives, but its 11 superseded originals are `UNAVAILABLE_NOT_PROVEN_RETAINED`; they were never accepted or issued, are not V5 predecessors, and do not establish complete replay of that failed review. Accepted V2/V3/A3 bytes remain separate predecessors; the current V4 candidate is used only for historical selector noncollision.

**Authority boundary:** this is implementation-only contract coherence, not A4 selection, B4 replay, C framed admission, D retention/readback, selector issuance, occurrence admission, acquisition, qualification, lifecycle D, production/public wiring, provider abstraction, or indexing/grouping. The ownership matrix's `UNIMPLEMENTED` entries remain open. Each private checkpoint requires its own focused tests and independent acceptance; the complete-frame limit belongs to C exact original header-plus-body accounting. No V6 is minted and no V5 original is modified.
