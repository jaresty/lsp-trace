Products are formed only after bounded integer validation; each unit still draws from the SAME remaining global grant. ## Opt-in activation notification

One nonblocking syscall writes <=512 bytes (POSIX minimum PIPE_BUF); EAGAIN, EPIPE, short write, invalid packet or cancelled/expired context fails closed without retry/poll/sleep. Kernel operations are before/after context-gated, not hard-interrupt promises.
