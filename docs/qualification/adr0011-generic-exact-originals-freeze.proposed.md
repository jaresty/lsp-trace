## Exact-byte candidate construction and selector fixture

Metadata only: UTF-8 Unicode scalar key order; shortest required JSON escaping, integral decimal numbers without exponent/leading zero, no insignificant whitespace or trailing newline. Reject duplicate *decoded* keys before canonicalization. Preserve array order, absent distinct from null, URI bytes without normalization. Wire frames, source bytes, params, result token and capability originals are binary originals, retained verbatim behind `{length,sha256,private_ref}`; metadata re-encoding never reconstructs them. This recipe requires independently reviewed vectors, including Unicode supplementary scalar versus UTF-16 ordering and escaped-key collision.

Candidate selector preimage is the concatenation of `uint64_be(byte_length) || exact_bytes` for, in order: ASCII `ADR0011-GENERIC-EXACT/PROPOSED/1`, selector token, method token, role token, raw schema-file SHA-256 hex, raw transport-policy SHA-256 hex, raw method-policy SHA-256 hex, session ID, canonical unsigned decimal generation, and SHA-256 hex of exact artifact original. Selector is `sha256:` plus lowercase SHA-256 of the entire preimage. Query domain additionally appends exact URI UTF-8 bytes, version UTF-8 bytes, source-original SHA-256, encoding ASCII, and decimal line and character. Occurrence domain additionally appends actual completed WRITE key, exact result-token SHA-256 and decimal original ordinal. Null/empty terminals have no occurrence ordinal. Neither selector nor hash substitutes for retained original bytes. No role hashes its own manifest or a terminal containing its own selector: select original first; calculate selector externally; put predecessor selectors only in later roles. The schema does not implement this recipe.

## Semantic replay predicates (not proved by schema)

Replay must retrieve and compare independently held exact originals before interpreting metadata; compare QUERY URI/version/source digest to actual SOURCE bytes and custody, and actual completed REQUEST_WRITE key to RESULT_READ key and the matched inbound frame's decoded ID. Count only a matching complete response frame, require strict framing and strict JSON grammar (reject duplicate decoded keys, including escaped collisions), preserve the original result token verbatim, require non-null token exactly when `result_present=true`, and verify its byte length/hash against the retained original. A false presence cannot be interpreted as `WHOLE_PARSE_SUCCESS`. Parse the whole result by method-specific grammar, then derive events and ordinals from that original, preserving duplicate occurrences. Verify each role's required predecessors by exact role, selector, digest, cardinality, common transaction identity and acyclic dependency; independently select POLICY/SCHEMA/SOURCE rather than trusting producer-provided hashes. PROCESS is optional, contextual, non-gating and cannot authenticate response authorship. Require committed TERMINAL with checked arithmetic and quota, independently re-read all selected originals and perform fresh external final readback after commitment; mismatch or unavailable evidence denies exact acceptance. Observed schema shape validation is distinct from asserted owner/original custody and does not establish either.

Canonical metadata review vectors: compare keys `\uE000` (BMP private-use scalar U+E000) and `\uD800\uDC00` (U+10000): Unicode scalar order puts U+E000 before U+10000, whereas UTF-16 code-unit order would reverse them. Parse `{\"a\":1,\"\\u0061\":2}` as duplicate decoded key `a` and reject before canonicalization. Shortest-escape UTF-8 output for ordered object is `{\"\":1,\"𐀀\":2}` (no trailing newline); these are strict-parser review vectors, not a claim that the proposal test exercises a canonicalizer.

## Quota and precedence fixture boundary

The 67,108,864 B mandatory transaction cap is independent of ≤256 documents each ≤4,194,304 B. Seventeen distinct 4 MiB documents are each category-valid yet exceed aggregate quota even *before* metadata, and must fail typed `RETENTION_QUOTA_EXCEEDED`, not silently omit originals. This is not an exact at-cap fixture: exact-cap/+1 requires measuring all actual serialized manifest/role/ref charges and separately isolating other ceilings; a configurable test-only quota Q/Q−1 is acceptable as an aggregate guard witness but does not prove the selected absolute boundary. Retained duplicate bytes are charged once only after exact-byte identity; every reference/manifest is charged separately. Worst-case reservation is checked before publication, reconciled to measured charge, rolled back on failure. Logical simultaneously owned buffer reservation 33,554,432 B is a separate counter, not Go heap. No generic 1,000,000 work-units counter: record only bytes scanned, messages processed, objects materialized, events emitted, documents acquired and logical buffer bytes reserved. A snapshot of executable bytes ≤536,870,912 B is optional, private, separately budgeted and cannot gate transaction admission or authenticate the responding process. Same-process monotonic access permits elapsed <86,400,000 ms, equality denies; cross-process disabled. Earliest causally reached guard wins (preflight; timeout; header/frame; cumulative wire; messages; decoded remarshal; raw result; source/buffer; objects/events; retention; readback), without reclassifying an earlier error.

## Review gaps

The candidate schema guards shape only: predecessor cardinality/ordering, strict JSON parsing, complete exact URI/source binding, actual keyed WRITE/READ, whole-result grammar, causal event accounting, owner snapshot semantics, no-replace publication, independently checked bytes and later external readback remain **unimplemented**. The schema's `PROCESS` branch cannot assert executable correspondence or response authorship. Selector digests above are calculated by independent Python and Go implementations, but semantic replay and independent original-byte custody remain unclosed. Synthetic offline tests are not real-provider qualification, original-byte replay, release authority or implementation acceptance. Independent reviewer must accept/revise exact URI bytes, frozen hashes, semantic cross-role constraints, canonical vectors and privacy/retention policy before any closed exact acceptance.
