## Proposed closed production contract for independent review

1. **Profile and declaration.** Start with only `GO_GOPLS_EXACT_V1`: exact READY managed Go/gopls session, registered clean Git worktree and pinned commit, UTF-16 position encoding as negotiated, exact query URI/point, one predeclared query per request, at most 16 declared inputs per acquisition. Require the revision and cleanliness evidence to be recorded at the stated custody level; a caller assertion must not become `PROVIDER_VERIFIED`. A dirty, unknown-revision, arbitrary-provider, or symbol-only query is ineligible. No implicit definition fallback can invent a references target.
2. **Owner-selected acquisition and retention.** Default off. Only concrete session ownership chooses a pinned 0700 private publication root, named versioned privacy/method/admission policies and hard limits; no transport/public caller supplies a selector, policy override, or root. Preserve exact independently checked session/generation/key, validated params, capability and provider *as reported*, matching completed write/read, prepared document URI/version/digest, revision/custody, result presence, exact successful raw payload, method and query identity. Bound params to 65,536 bytes, result to 1,048,576 bytes, encoded object to **1,500,000 bytes**, and independently bound live wire/messages/time/work/aggregate retention. Optional exact frames and their 24-hour diagnostic window are **not** required for canonical replay. Retain canonical payload for the derived artifact's reviewed lifetime; remove only under an explicit reviewed decision. Missing/withheld/removed payload bars *new* admission. `COMMITTED_VERIFICATION_FAILED` records potentially committed bytes but issues no verified receipt.
3. **Terminal request and element ledgers.** Declare N before invocation; record whether each query began and reached one closed terminal disposition. Keep N, returned elements E (unknown if no complete bounded top-level value), parsed elements P, and admitted occurrences A separate. For a fully valid two-item references result: N=1, E=2, P=2, and A=2 only after both receipt and target admission checks. A malformed second element yields request `MALFORMED` and A=0: any diagnostic valid-prefix count is not the whole-result parser output and cannot issue an occurrence; do not fabricate outcomes for unbegun later elements. No transport failure, unsupported capability, `null`, `[]`, invalid or withheld payload can be relabeled `COMPLETE_EMPTY` without the independently verified full denominator and applicable precedence. Preserve original zero-based ordinals and duplicates.
4. **Target and occurrence admission.** Verify the independently retained document-symbol transaction and query-target receipt against *the same* URI, point, encoding, revision/custody, session/generation and prepared document version/digest. Re-run the unique strict most-specific nested selection-range rule. A references result never creates a target. Only after separately replaying the exact references transaction, verifying terminal accounting and selected policy may an immutable `REFERENCES_SYMBOL` occurrence be issued per valid returned location, oriented `REFERENCING_OCCURRENCE` → `REFERENCED_SYMBOL` and bound to exact method/receipt, roles, range, ordinal and identity. A mismatch, unknown version/kind, duplicate key, malformed/partial result, nonterminal query, absent target, withholding, or over-limit input yields **zero newly admitted occurrences**. Record exclusion reasons; zero admission is not automatically `COMPLETE_EMPTY`.
5. **Replay and compatibility.** Freeze a closed versioned canonical receipt, terminal ledger, occurrence schema and content-addressed selectors/digests with independent expectation checks. Offline replay must check exact bytes, no-replace verified publication, identity, original ordinals, balances, and cross-object links; a self-hash alone is insufficient. Preserve historical omitted-selector `CALLS_ONLY`, `MaxInputs=16`, `PolicyBytes`, strict `NODE_CONFLICT`, all existing CALLS schemas/bytes, and the private typed Program C rejection. Do not feed Leiden, change public CLI/MCP, choose grouping thresholds, or claim source-context completeness at this gate.

## Required falsification before *production* admission

- Real clean registered Go/gopls worktree, owner-selected default-off capture, independently recorded pre-invocation N and capability/provider observation; demonstrate exact keyed result/params/document/revision binding before and after publication. Synthetic peer tests are controls, **not** a replacement.
- Cross-object replay substitutions: URI, query point, encoding, source digest/version, revision/custody, session/generation/key, method, params formatting, result, provider/adapter/policy, selector/digest, unknown fields, duplicate keys, trailing bytes, and repeated equal locations. Require original distinct ordinal occurrence IDs only on valid eligible input.
- Terminal matrix: absent capability with zero invocation, server error (including present code 0 vs absent), timeout/cancel, partial/short write or read, missing result vs `null`/`[]`, malformed later required member, 1000/1001 item bound, pre/post-limit exhaustion, withheld payload, and preexisting or late-failed publication. No failure may manufacture a valid prefix occurrence or complete request. Test N/B/T/E/P/A and exact failed ordinal independently.
- Privacy and resource matrix: exact per-record boundaries, total objects/bytes/work/wire bounds, private-root replacement and cleanup accounting, redacted diagnostics, review-time retention and removal. Optional diagnostic frame loss must not remove required canonical payload; missing canonical payload bars admission.
- Deterministic replay, input-order permutation, and historical CALLS-only bytepin/omitted-selector tests. Qualify mixed grouping policy and source context **after** occurrence admission; neither is authorized by this contract review.

## Independent maintainer decision requested

Please review the five proposed contract clauses and falsification matrix **independently**. Record `ACCEPT_CONTRACT_FOR_IMPLEMENTATION`, `REVISE` (with exact clause and counterexample), or `DECLINE`. Contract acceptance authorizes implementation/testing **only**; production occurrence admission remains disabled until a second, explicit maintainer `QUALIFIED` decision over pinned implementation/policy digests, frozen corpus/held-out results, complete terminal and privacy evidence, and the resulting immutable occurrence artifacts. Silence, a subagent opinion, this draft, or passing synthetic tests is `INCOMPLETE`, not acceptance.
